This test verifies basic functionality over the internal speakers and microphone.

Test Setup:
• It may be necessary to go to the "Sound & vibration" settings panel to set the volume level for the output device.
• With no audio peripherals connected, adjust the "Media volume" to max.
• Make sure speakers and microphones are not covered.
• Place the DUT in a quiet environment with minimal reflection and vibration. An acoustic anechoic box is ideal.

Test Execution:
• Select the "Native API" button.
• Press the "Start" button. The test will delay for 5 seconds and then step through the list of data paths playing a tone and noting its presence or absence.
• Select the "Java API" button.
• Press the "Start" button to repeat each data path test for the Java API.

Test Completion:
• Once each of the data paths and APIs have been measured, and a signal detected, the test can be marked successful.
