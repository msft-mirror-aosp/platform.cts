This panel allows you to set levels for loopback signals

The process is as follows:

  1. Select the input and output devices on which the loopback is executing.
  2. Select a channel from the Channel selection spinner.
  3. Click "Start" to play a sine wave on the selected channel of the selected output device.
  4. Use the volume control on the DUT and/or external peripheral to set an appropriate signal level.
  5. Repeat the process for other channels. Note: You must stop the audio before selecting a different channel.
